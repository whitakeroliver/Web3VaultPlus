# Web3VaultPlus

Web3VaultPlus is a blockchain-enabled, distributed-architecture suite for automated key management and decentralized data storage.

With Web3VaultPlus, you get a lightweight tool that stays out of your way.

**What you get**

- Web3VaultPlus is a blockchain-enabled, distributed-architecture
- suite for automated key management
- and decentralized data storage

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/Web3VaultPlus.git`
2. `cd Web3VaultPlus`
3. Install in editable mode: `pip install -e .`

## Configuration

Web3VaultPlus is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
